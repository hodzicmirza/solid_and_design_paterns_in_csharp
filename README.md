# SOLID & Design Patterns u C#

Ovo je projekat rađen u sklopu **Skyline Talent Programa** gdje sam kroz praktične primjere u C#-u obradio osnove Objektno Orijentisanog Programiranja (OOP), SOLID principe i najčešće dizajn paterne.

## Struktura projekta

- **`OOP/`** – Osnovni koncepti (Apstakcija, Enkapsulacija, Polimorfizam, Nasljeđivanje, Kompozicija, Zavisnost).
- **`SOLID/`** – Primjeri za svih 5 SOLID principa (SRP, OCP, LSP, ISP, DIP).
- **`DIZAJN_PATERNI/`** – Implementacije kreacijskih, strukturnih i paterna ponašanja.
- **`Program.cs`** – Glavna klasa za pokretanje i testiranje primjera.

## Nacin pogretanja projekta

1. Otvori projekat u terminalu / VS / VS Code.
2. Pokreni komandu:
   ```bash
   dotnet run
   ```
